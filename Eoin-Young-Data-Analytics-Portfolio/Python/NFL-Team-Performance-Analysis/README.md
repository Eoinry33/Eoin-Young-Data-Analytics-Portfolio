# NFL Team Performance Analysis

## Goal
Evaluate which team-level performance metrics are most closely associated with winning.

## Method
This project uses a reproducible synthetic game dataset to demonstrate season aggregation, win percentage, point differential, correlation analysis, and team ranking.

The data is synthetic and explicitly labeled so the portfolio does not present invented statistics as real NFL results.

## Key Questions
- How does point differential relate to win percentage?
- Which team metrics best separate strong and weak teams?
- How can a simple team-strength report be communicated visually?
