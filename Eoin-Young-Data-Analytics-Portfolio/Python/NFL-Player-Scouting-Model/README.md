# NFL Player Scouting & Evaluation Model

## Goal
Create a transparent quantitative framework that supplements traditional scouting by comparing players against peers at the same position.

## Method
The project standardizes production, consistency, availability, and peak performance within each position. A composite score creates a ranking that can be used as one input into a broader scouting process.

## Important
This is **not a claim that statistics alone can scout an NFL player**. Film, role, scheme, competition, injuries, athletic testing, character, and coaching context matter. The dataset included here is synthetic for demonstration.
