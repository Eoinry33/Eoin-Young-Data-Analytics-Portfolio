# Eoin Young — Data Analytics & Sports Analytics Portfolio

I’m a Miami University graduate with a background in Data Analytics and Sports Leadership & Management. I built this portfolio around the type of work I want to do professionally: turning sports data into something a coach, scout, front office, or business team could actually use.

The projects here are not classroom exercises copied from tutorials. I’m using public sports data, writing the analysis myself, documenting the decisions I made, and trying to answer questions that go beyond simply ranking players or teams.

## Data sources

The NFL projects use public 2024 data from nflverse, NFL.com, ESPN, Pro-Football-Reference, and FantasyPros. nflverse provides open NFL data releases and Python/R tooling for accessing play-by-play and player statistics. The college basketball project uses public 2023-24 data from Sports-Reference and WarrenNolan.

I do not claim ownership of third-party data. Each project contains a source note explaining where the data came from and how it was used.
