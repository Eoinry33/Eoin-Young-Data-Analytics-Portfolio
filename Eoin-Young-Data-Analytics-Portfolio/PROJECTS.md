# Project Index

## Python

### NFL Team Performance & Attendance
Real 2024 NFL team records, scoring margins and attendance.

### NFL WR Opportunity & Efficiency Model
Real 2024 WR data transformed into a custom evaluation score.

### Fantasy Football WR Production Model
Real 2024 WR data analyzed with Ridge regression.

## R

### College Basketball Offensive Profiles
Real 2023-24 college basketball data comparing scoring, efficiency and winning.

## SQL

### NFL Analytics Database
PostgreSQL schema and analytical queries using the same public 2024 NFL data.

## Excel

### NFL Attendance Dashboard
A business-facing Excel dashboard using 2024 attendance and team performance.

The projects intentionally overlap in data in a few places. That is useful because it shows how the same source data can be approached with different tools and different questions.
