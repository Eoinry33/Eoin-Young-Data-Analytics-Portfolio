# Sports Business Dashboard

## Goal
Build an executive-style dashboard that demonstrates KPI reporting, spreadsheet modeling, formulas, and sports-business communication.

## Dataset
The workbook uses a **synthetic sports-business dataset**. It is intentionally labeled so the portfolio never presents invented organizational numbers as real.

## KPIs
- Total attendance
- Attendance rate
- Ticket revenue
- Average ticket price
- Revenue per attendee

## Skills
Excel formulas, KPI design, dashboard development, trend visualization, reporting.
