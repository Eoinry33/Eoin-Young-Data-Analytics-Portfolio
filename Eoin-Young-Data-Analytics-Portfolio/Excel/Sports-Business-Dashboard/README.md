# NFL Attendance & Performance Dashboard — Excel

## What this dashboard is for

I wanted an Excel project that looks more like a small sports-business report than a spreadsheet full of formulas.

The dashboard combines 2024 NFL team performance with home attendance so a user can quickly compare:

- wins
- win percentage
- point differential
- home games
- total home attendance
- average home attendance

## Why attendance?

Attendance is one of the clearest publicly available ways to look at fan engagement at the team level.

It is not a perfect measure of demand because stadium capacity, market size, pricing, opponent mix and stadium configuration all matter.

That is exactly why I think it is useful as an analytics question rather than a simple leaderboard.

## Questions I would ask from this dashboard

- Which teams have strong attendance but weak records?
- Which teams have strong records but relatively modest attendance?
- Does point differential explain attendance better than wins?
- Are certain divisions consistently stronger or weaker?
- Which markets could be interesting for a deeper fan-engagement study?
