# College Basketball Statistical Analysis

## Goal
Use R to examine the relationship between offensive scoring, defensive scoring, and team wins.

## Dataset
The included CSV is a **synthetic college-basketball-style dataset** created for reproducibility. It is clearly labeled and is not presented as actual team records.

## Methods
- Data cleaning with tidyverse
- Descriptive statistics
- Correlation analysis
- Linear regression
- ggplot2 visualization

## Files
- `basketball_analysis.R`
- `synthetic_college_basketball.csv`
- `scoring_vs_wins.png` (generated by the script)
